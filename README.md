# 🎮 FNF Mod Manager

Лёгкий графический менеджер модов для **Friday Night Funkin'** под Windows.
Написан на PowerShell + Windows Forms. Не требует установки, сторонних программ или .NET Runtime (всё встроено в Windows).

## ✨ Возможности

* **Управление модами**: Быстрое включение и выключение модов (перемещение между папками `mods` и `mods_disabled`). Поиск по названию.
* **Профили**: Сохраняйте наборы активных модов (например, «Сюжетка», «Хардкор») и переключайте их в один клик.
* **Безопасное резервное копирование**: Создание ZIP-архивов модов и их восстановление. Архив сначала распаковывается во временную папку, поэтому даже битый архив не сломает текущий мод.
* **Запуск игры**: Автоматический поиск exe-файла игры и запуск прямо из менеджера. Программа не даст изменить моды, если игра запущена.
* **Поддержка любых движков**: Работает на файловом уровне, поэтому подходит для официального движка, Psych Engine, Kade Engine и других.
* **Тёмная тема**: Приятный глазу интерфейс.

## 🖥️ Системные требования

* Windows 10 или Windows 11 (также работает на Windows 7/8.1 с PowerShell 5.1)
* Windows PowerShell 5.1 (встроен в систему)

## 🚀 Установка и запуск

1. Скачайте файлы `FNF-ModManager.bat` и `FNF-ModManager.ps1` (или скачайте ZIP-архив из раздела **Releases**).
2. Положите оба файла в одну папку (например, рядом с игрой или на рабочий стол).
3. Запустите **`FNF-ModManager.bat`**.

> ⚠️ **Важно:** Запускайте именно `.bat` файл. Он автоматически обходит ограничения политики выполнения скриптов Windows и запускает менеджер.

При первом запуске программа сама создаст файлы настроек (`config.json`), профилей (`profiles.json`) и папку для бэкапов (`backups`).

## 📂 Как это работает

Программа работает с двумя папками:
* `mods` — активные моды, которые видит игра.
* `mods_disabled` — выключенные моды, которые игра не видит.

При нажатии «Выключить» или «Включить» менеджер просто перемещает папку мода из одной директории в другую. 

## 🛡️ Безопасность

* Программа не делает никаких сетевых запросов.
* Операции блокируются, если процесс игры (`Funkin.exe` и т.д.) запущен.
* Все действия записываются в журнал `history.log`.
